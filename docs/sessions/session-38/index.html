9. Reflection Questions

  1. Why check response.ok?

    fetch rejects on network failure, but HTTP error statuses still resolve to Response objects.

  2. Why normalize in the service?

    It isolates API churn and keeps every component from learning external field names and nesting.

  3. Why request selected fields?

    Smaller responses reduce transfer and make the dependency contract explicit.

10. What Breaks If This Boundary Is Ignored?

  • Responsibilities drift across unrelated modules.
  • Safe changes become harder to verify and explain.
  • Future learners inherit coupling without its original reasoning.

11. What Engineering Concept Was Learned Today

A network service protects the app by validating and translating data at the boundary.
