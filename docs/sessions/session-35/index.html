9. Reflection Questions

  1. When is prop flow not a problem?

    When intermediate components meaningfully use the values or the path is short and explicit.

  2. What evidence suggests drilling pain?

    Several components accept props solely to forward them, and unrelated APIs change whenever the distant consumer changes.

  3. Why not immediately add context?

    Context hides dependencies and broadens update reach; it should solve measured cross-tree sharing, not aesthetic discomfort.

10. What Breaks If This Boundary Is Ignored?

  • Responsibilities drift across unrelated modules.
  • Safe changes become harder to verify and explain.
  • Future learners inherit coupling without its original reasoning.

11. What Engineering Concept Was Learned Today

Prop drilling is diagnosed by unnecessary couriers, not by the mere existence of props.
