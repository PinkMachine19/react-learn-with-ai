3. The Concept — One Door to the Data

A service layer is a plain JavaScript module. It does not render JSX. It exposes operations and keeps its data source private.

import countries from '../mock/countries.json';

export function getAllCountries() {
  return [...countries];
}

Queries belong with data access

export function getCountryById(id) {
  return countries.find(country => country.id === id);
}

export function getCountriesByRegion(region) {
  return countries.filter(country => country.region === region);
}

The caller says what it needs. The service decides how to obtain it. Today those returns are immediate values; Session 25 will preserve the same operations while changing their timing.

Naming matters: use one filename consistently: countryService.js. A near-duplicate such as countryServices.js creates confusing imports.
