// One defensible solution
function externalEffects(tasks) {
  const external = new Set(['set document title', 'subscribe to resize']);
  return tasks.filter(task => external.has(task));
}
Filtering and totals are render-time derivations; the other tasks synchronize externally.

9. Reflection Questions

  1. Why is filtering usually not an effect?

    It is a pure derivation from current props/state and can be computed during render.

  2. What does cleanup protect?

    It undoes subscriptions and prevents obsolete asynchronous work from affecting the current UI.

  3. What causes a common effect loop?

    The effect updates a dependency that changes on every run, triggering setup repeatedly.

10. What Breaks If This Boundary Is Ignored?

  • Responsibilities drift across unrelated modules.
  • Safe changes become harder to verify and explain.
  • Future learners inherit coupling without its original reasoning.

11. What Engineering Concept Was Learned Today

An effect is a synchronization boundary, not a general place for application logic.
